부가세 계산기

부가세가 포함된 공급대가를 입력하면 공급가액과 부가세를 바로 나눠드립니다.

원
공급가액 = 공급대가 × 100 / 110  ·  부가세 = 공급대가 − 공급가액
공급가액 0원
부가세 0원
검산 0 + 0 = 0
방식부가세율 10% 과세 거래에서, 합계금액(공급대가)만 알 때 역산하는 계산입니다.
주의1원 단위 반올림 차이가 생길 수 있어 공급가액 = 반올림(공급대가 ÷ 1.1)로 먼저 구하고, 부가세는 공급대가 − 공급가액으로 계산해 두 금액의 합이 항상 원래 금액과 정확히 일치하도록 했습니다.
